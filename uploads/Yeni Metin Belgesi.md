# Milano Building Detection

**Deep learning-based satellite image segmentation**

Trained a U-Net model to automatically detect building footprints from satellite imagery. Study area: Via Luca Ghini, Milan — the neighborhood where I lived during my Erasmus exchange.

## Overview

Combined Sentinel-2 satellite imagery with open-source map data to teach a neural network to identify buildings at pixel level. The model achieved **85.1% IoU**, a performance level considered professional research-grade in academic literature.

## Stack

- **Python**, PyTorch, U-Net (31M parameters)
- **Sentinel-2** imagery via Microsoft Planetary Computer
- **Overture Maps** building polygons (8,500+ buildings)
- Google Colab + NVIDIA Tesla T4 GPU

## Results

| Metric | Value |
|--------|-------|
| Mean IoU | 85.1% |
| Training time | ~6 minutes |
| Generalization test | Consistent on unseen region |
